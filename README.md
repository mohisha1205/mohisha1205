## 🚀 Projects

### 🧠 [BrainGNN – Interpretable Brain Graph Neural Networks](https://github.com/mohisha1205/BrainGNN_Pytorch)

**Python · PyTorch · Graph Neural Networks · Neuroimaging**

Exploring graph-based deep learning for neuroimaging through the implementation and optimization of BrainGNN for Autism Spectrum Disorder (ASD) classification using the ABIDE-I resting-state fMRI dataset.

- Constructed brain connectivity graphs using the CC200 atlas, representing 200 brain regions as graph nodes.
- Implemented graph construction using Pearson correlation, partial correlation, top-K sparsification, and Graph Diffusion Convolution (GDC).
- Worked with ROI-aware graph convolution and pooling mechanisms to capture discriminative brain connectivity patterns.
- Developed a stratified 5-fold cross-validation pipeline with early stopping and performance evaluation.
- Achieved **62.9% mean classification accuracy**, improving upon the initial baseline of approximately 51%.

### 🩻 [DualA-Net – Medical Image Segmentation](https://github.com/mohisha1205/DualA-Net-Image-Segmentation-Model-Implementation)

**Python · PyTorch · Deep Learning · Computer Vision**

Implemented DualA-Net for retinal blood vessel segmentation using the CHASE_DB1 dataset.

- Developed a deep learning pipeline for medical image segmentation.
- Implemented a combined Binary Cross-Entropy and Dice loss function.
- Evaluated performance using accuracy, specificity, Intersection over Union (IoU), and Dice coefficient.
- Achieved **96.69% accuracy**, **98.66% specificity**, and **0.7275 Dice score**.

### ⚙️ [Multithreaded Web Server in C++](https://github.com/mohisha1205/multi-threaded-web-server)

**C++ · Socket Programming · POSIX Threads · Semaphores · HTTP**

Built a multithreaded HTTP web server from scratch to explore systems programming and concurrent request handling.

- Implemented TCP socket communication using the Berkeley sockets API.
- Used POSIX threads to handle multiple client connections concurrently.
- Implemented HTTP GET and POST request parsing and handling.
- Supported static file serving for HTML, CSS, and other resources.
- Used semaphores for thread synchronization and enforced a maximum concurrent thread limit.
- Integrated request logging for monitoring server activity and debugging.
